# Лобби и контейнерный запуск

Создание комнаты и вход — HTTP. Снимки состава и готовность — Socket.IO через тот же origin. Сервер выдаёт случайный токен участника; в памяти хранится SHA-256, публичные снимки не содержат токенов. Код приглашения позволяет вступить, но не управлять чужим игроком.

В браузере сессия сохранена отдельно для каждой комнаты. Несколько вкладок считаются одним участником; готовность сбрасывается после отключения последнего соединения. Явный выход отзывает членство во всех вкладках. При выходе ведущего роль получает следующий участник.

Текущие ограничения: один процесс API, хранение комнат в памяти, до 200 комнат, до 8 участников, срок жизни 2 часа. Перезапуск API удаляет лобби. Каталог хранится в PostgreSQL, комнаты ещё не перенесены в Redis. Перед публичным запуском нужны ограничение частоты запросов, управление покинувшими игру участниками и постоянное хранение активных матчей.

Docker Compose поднимает PostgreSQL, одноразовый процесс миграций, API, Next.js и Caddy. Все браузерные HTTP/WebSocket запросы идут через Caddy на одном порту. Приложения работают от пользователя node; секреты из локального .env не попадают в образ. Образ пока содержит зависимости сборки для выполнения Prisma CLI; уменьшение runtime-образа — отдельная оптимизация.

В CI добавлен запуск Compose и smoke-проверка двух участников: создание, вход, WebSocket, готовность, переподключение, передача ведущего, выход. Локально запускается через `pnpm test:smoke` после поднятия приложения. Дополнительный `pnpm test:game` проверяет полный матч, см. GAMEPLAY.md.

## Зал ожидания

Лобби компании использует две колонки: приглашение/игроки и настройки организатора. На узких экранах секции идут последовательно. Код и ссылка копируются отдельно. Состояние подключения, готовность и организатор видны в карточках игроков.

Организатор меняет режим, категорию и длительность раунда через `room:settings`. Сервер проверяет полномочия, отсутствие активной партии и наличие полноценной подборки. После изменения готовность сбрасывается у всех. Для старта нужны двое подключённых готовых игроков. Недоступные категории отключены; причина ожидания показана над кнопками старта.

## Навигация и компоновка

Общая шапка: главная, друзья (`/play/party`), соло (`/play/solo`), батл, звук, профиль. Звук расположен в потоке шапки, а не поверх страницы. На мобильном навигация переносится отдельной строкой. Главная больше не содержит большую форму создания игры; карточки механик ведут на одиночную настройку с выбранным `mode`. У авторизованного пользователя ник в форме заполняется из профиля.

Убраны дубли логотипа и кода над залом ожидания. Колонки лобби имеют ограничение минимальной ширины, fieldset разрешено сжиматься; панель готовности закреплена у нижнего края при прокрутке.
