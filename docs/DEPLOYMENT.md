# Тестовый деплой «Кадрово» на Render

## Что уже настроено

`render.yaml` создаёт один бесплатный Docker Web Service и отдельную бесплатную PostgreSQL в Frankfurt. В контейнере Caddy принимает `PORT`, отправляет `/api/*` и `/socket.io/*` в Nest, остальное в Next. HTTPS завершается на Render. Приложение автоматически берёт публичный origin из `RENDER_EXTERNAL_URL`; для собственного домена нужно указать `WEB_ORIGIN=https://...`.

При каждом старте выполняется `prisma migrate deploy`. Ошибка миграции прерывает запуск. Завершение любого из трёх процессов останавливает контейнер. Не увеличивать число экземпляров: комнаты и очередь соперников пока находятся в памяти одного процесса.

## Публикация кода

1. Авторизовать GitHub (`gh auth login`) или подключить GitHub в Codex.
2. Создать приватный репозиторий `kadrovo`, загрузить ветку `main`. `.env`, `.data`, дампы базы, зависимости и локальные изображения исключены из Git и Docker build context.
3. В Render: New → Blueprint → выбрать репозиторий → `render.yaml`.
4. Указать ключ провайдера через секретные Environment Variables. Не добавлять его в YAML или GitHub.
5. Проверить `/api/health`, создание комнаты в двух браузерах, ответы/подсказки, перезагрузку страницы и переподключение Socket.IO.

## Важное ограничение бесплатного варианта

Это конфигурация для проверки запуска, а не готовый перенос локального каталога. Сервер засыпает после 15 минут бездействия; локальные файлы исчезают при перезапуске/деплое. Бесплатная база истекает через 30 дней, её объём — 1 GB. Игры в памяти прерываются при рестарте. Next + Nest + обработка изображений могут превысить память бесплатного сервера: тогда потребуется платный экземпляр, это проверяется по метрикам первого деплоя.

Для показа с большим постоянным каталогом нужно выбрать платный Web Service с persistent disk либо вынести изображения в объектное хранилище. Бесплатный Blueprint намеренно отключает `CONTENT_AUTO_SYNC`, чтобы не тратить квоту провайдера на файлы, которые исчезнут при засыпании.

Вариант с диском (оплачивается отдельно; перед созданием проверить цену в Render): изменить `plan` web-сервиса на `starter` и добавить:

```yaml
disk:
  name: content
  mountPath: /app/data
  sizeGB: 10
```

После выбора постоянного хранилища перенести каталог и изображения, затем включить `CONTENT_AUTO_SYNC=true`. На новых дисках проверить доступ на запись пользователя `node`; запуск прекращается, если создать CONTENT_DIR не удаётся. Не запускать приложение от root ради обхода прав.

## Каталог и данные пользователей

База и файлы — отдельные части каталога. Перенести только таблицы `Title`, `TitleAlias`, `ExternalId`, `Asset`, `Puzzle` с сохранением UUID и файлы из `CONTENT_DIR`. Восстановление делать в пустой каталог после миграций и до включения импорта. Локальные `Account`, `Identity`, `AuthSession`, `AuthChallenge`, `BattleResult` не переносить: для показа создать новые аккаунты. Не коммитить SQL/архивы в репозиторий.

Автоматически загруженные изображения имеют отдельные редакторский статус и статус прав. Публичное окружение не включает локальный режим `LOCAL_CONTENT_PREVIEW`: нужны разрешённые для публикации изображения и заполненное основание (`permissionReference`). Перенос SQL не должен подменять эти статусы. Без этого локальные 878 загадок не становятся автоматически доступными в публичном каталоге. Демоиллюстрации встроены и доступны независимо от провайдера.

## Вход и почта

Mailpit — только для локальной разработки. На бесплатном Render заблокированы исходящие SMTP-порты 25/465/587. Текущему SMTP-транспорту нужен провайдер с разрешённым альтернативным портом, либо потребуется добавить отправку через HTTPS API. Без этого подтверждение почты и восстановление пароля в облаке не заработают. Не показывать в интерфейсе токены подтверждения как обход.

Для Yandex/Twitch зарегистрировать отдельные приложения или добавить адреса callback нового окружения, затем задать `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`. Callback-адреса: `https://<домен>/api/auth/oauth/yandex/callback` и `https://<домен>/api/auth/oauth/twitch/callback`. Локальные localhost callback не подходят для публичного домена.
