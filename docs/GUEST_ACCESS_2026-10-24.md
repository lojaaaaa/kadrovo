# Локальные правки интерфейса и гостевой доступ — 24 октября 2026

Ничего не отправлено на GitHub или Render.

## Интерфейс

- Убрана подборка недели. Общий компактный переключатель формата ответа используется в соло, создании комнаты и лобби.
- Выровнены заголовок соло и иконка, отступы настроек; подборки заменены компактной сеткой без пересечения текста. Исправлены слишком широкие CSS-селекторы, задававшие фиксированную высоту вложенным карточкам.
- «Мои фильмы» закрыты по умолчанию. Содержимое и запросы библиотеки включаются только после раскрытия.
- Главная и онлайн ожидают необходимые данные целиком, показывая скелетон вместо промежуточных значений. Соло также ожидает доступы. Ошибки главной имеют повторную загрузку.

## Гостевые правила

- 5 начатых одиночных игр, включая «Раньше или позже»; ежедневный фильм не расходует лимит.
- 3 начатые онлайн-игры без рейтинга. Общий лимит для быстрых дуэлей, компании и комнат.
- Очередь, отмена поиска, повторное подключение и повтор одного запроса запуска не расходуют дополнительные попытки.
- Можно создавать приватные комнаты по ссылке и присоединяться к комнатам в пределах лимита. Публичная комната и рейтинговая дуэль требуют аккаунта.
- По исчерпании лимита сервер возвращает явную причину, интерфейс открывает вход/регистрацию. При гостевом отказе в комнате клиент выходит из неё перед переходом.
- Для аккаунта лимиты не применяются. Быстрые игры без рейтинга не передают аккаунты в рейтинговый расчёт.

Счётчики привязаны к существующей HttpOnly cookie гостя и сохраняются в истории в БД. Это пробный доступ в браузере: очистка cookie создаёт нового гостя. Проверка и запись рассчитаны на существующий один экземпляр API; для горизонтального масштабирования нужны транзакционные счётчики. Запись использует существующую очередь сохранения истории с повторными попытками, а не отдельную синхронную транзакцию.
