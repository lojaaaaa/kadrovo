# Загрузка, режимы и лобби — локальные правки 24.10.2026

Ничего не опубликовано и не отправлено в GitHub.

- Фильм дня: до получения актуального прогресса показывается скелетон вместо предположения «Угадать». При ошибке загрузки есть повтор запроса. На входе/выходе аккаунта сбрасываются персональные кеши, чтобы не показывать историю другого состояния авторизации.
- Скелетоны добавлены для начальной загрузки формы создания комнаты и соединения с комнатой. Динамические счётчики не подменяются нулями во время загрузки.
- Пиксели формируются из полного постера (последняя стадия лупы), а не первого кадра. Постерный вертикальный плеер используется и в пикселях. Это расширило пул пикселей до 1614 фильмов.
- Кеш миниатюр сохраняет все пять стадий текущего раунда и очищает прошлые раунды целиком. Добавлен регрессионный тест на четыре последовательных раунда.
- «Раньше или позже» теперь пятая полноценная карточка выбора режима; собственная кнопка «Играть» открывает его. Для него скрыты не относящиеся к нему формат ответа, недельная подборка и дополнительные настройки. Формат ответа обычной игры стал компактным переключателем.
- Параметры лобби располагаются в две колонки на широком экране. «Общий вкус» перенесён из отдельной верхней плашки к дополнительным параметрам. На телефонах поля последовательно перестраиваются в одну колонку. Длинный список игроков имеет ограниченную высоту и внутренний тёмный скролл.
- Клиент ждёт подтверждения выхода сервера перед отключением сокета. Последний явный выход удаляет комнату сразу. При закрытии всех вкладок есть 60 секунд для переподключения, затем комната удаляется. Возврат во время паузы отменяет удаление; это покрыто тестом.
- Вход по приглашению стал компактным и перенесён выше списка лобби.
- В «Моих фильмах» появились компактная шапка, показатели, аккуратное пустое состояние списка просмотра и отдельная история ежедневных игр. Количество в истории исключает сегодняшний фильм.
- Форма создания стала короче: необязательные подборки, общий ответ и предпочтения свёрнуты; убраны дублирующие пояснения и лишние отступы.

## Проверки

131 unit test, lint и TypeScript прошли. Сборка Docker прошла. Smoke комнат, игры, персональной истории/daily и хронологии прошли. Проверка комнат дополнена HTTP 404 после ухода последнего игрока. Проверка адаптации охватывает 11 разделов на 1366×768 и 360×640: горизонтального переполнения нет. Длинные каталоги/профиль на телефоне прокручиваются естественно; запрета вертикальной прокрутки нет.

Повторные перезагрузки главной не показывали ложный призыв «Угадать» после уже завершённой ежедневной игры. Часть быстрых снимков попадает на общий переход/скелетон, поэтому не считаем их доказательством показа самого результата до ответа сервера.

Финальная форма создания комнаты помещается на 1366×768 без вертикальной прокрутки (высота формы 563,5 px). Само лобби с основными настройками и кнопками запуска также помещается на этом размере. Постеры в поиске, итогах и списке просмотра используют общий компонент с изображением-скелетоном и fallback при ошибке загрузки. Скриншоты и измерения сохранены в `docs/qa-2026-10-24-polish/`.
