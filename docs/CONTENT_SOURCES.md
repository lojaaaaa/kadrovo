# Источники контента: выбор для Filmless

Первичное документальное исследование от 22.10.2026. Актуальное решение и результаты реальных запросов с настроенными ключами от 23.10.2026: [CONTENT_DECISION.md](CONTENT_DECISION.md). Указания ниже об отсутствии ключей относятся к первому этапу исследования.

## Рекомендация

Начать сравнение с **ПоискКино и Kinopoisk API Unofficial**, затем добавить **TMDB только для недостающих постеров и сериальных кадров**. Не подключать три платных зависимости заранее. ПоискКино потенциально закрывает оба вида контента; по одной документации нельзя доказать, что отдельный поставщик кадров лучше.

В продакшене API нужны для импорта, а игра использует собственный отредактированный каталог с разрешёнными материалами. Поиск названия во время раунда не должен зависеть от квоты внешнего сервиса.

## Сравнение

| Источник                 | Метаданные и русские названия                             | Постеры                      | Кадры                                                              | Решение                                            |
| ------------------------ | --------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------------ | -------------------------------------------------- |
| ПоискКино v1.5           | Русские названия, альтернативные имена, внешние ID и типы | В карточке произведения      | `/image`: frame, still, screenshot и другие типы                   | Первый кандидат на единый источник                 |
| Kinopoisk API Unofficial | Карточки и русские названия                               | posterUrl и POSTER           | Отдельный фильтр STILL                                             | Сравнить реальные кадры на тех же ID               |
| TMDB                     | Переводы и международные ID                               | Локализованные poster images | Movie backdrops; изображения TV episodes                           | Дополнение при конкретных пробелах                 |
| TVmaze                   | Сериалы и эпизоды; русский каталог не гарантирован        | Изображения шоу              | Изображения эпизодов, не богатая галерея сцен                      | Резерв для отдельных сериалов, не основной каталог |

## Подтверждённые детали интеграций

### ПоискКино

`GET /v1.5/movie/{id}` — карточка; `GET /v1.5/image?movieId={id}&limit=50` — изображения. Авторизация заголовком X-API-KEY. В опубликованной схеме изображений подтверждены поля type, url, previewUrl, height, width; типы frame, still, screenshot, shooting, promo, cover, backdrops, wallpaper. Пагинация cursor-based: next/hasNext, не page из старых примеров.

Типы произведений: movie, tv-series, cartoon, animated-series, anime. Категории Filmless должны определяться редактором с приоритетом анимации, чтобы мультсериал не попал в игровые сериалы.

На сайте: demo 200 запросов/сутки и ограничение пагинации; базовый 5 000/сутки за 2 500 ₽/месяц; заявленный безлимит 5 000 ₽/месяц. Лимиты и права для production нужно подтвердить перед покупкой. [Тарифы](https://poiskkino.dev/).

### Kinopoisk API Unofficial

`GET /api/v2.2/films/{id}` и `GET /api/v2.2/films/{id}/images?type=STILL&page=1`. Не смешивать STILL с SHOOTING (со съёмок) и PROMO. По документации существует пагинация; недостаточно проверить одну страницу и объявить полную библиотеку маленькой.

Предыдущая проверка главной показала 500 запросов/сутки для новых пользователей, а документация — 25 req/s. Цена расширения публично не подтверждена; ссылка rates возвращала страницу «не найдено». Для нового подключения перепроверить условия аккаунта. [Документация](https://kinopoiskapiunofficial.tech/documentation/api/).

### TMDB

`/3/movie/{id}/images` возвращает backdrops, posters и logos; backdrop не обязательно является настоящим кадром. Для сериалов полезнее `/3/tv/{series_id}/season/{season}/episode/{episode}/images`: источник адресуется по эпизоду, но игровой ответ привязан к внутреннему ID сериала. Постеры сериала брать отдельно на уровне TV series.

Перебор всех эпизодов дорог по запросам: сначала выбрать несколько репрезентативных эпизодов, оценить покрытие, затем расширять. Поиск кадров нельзя привязывать к ходу игрока.

Для сопоставления использовать внешний IMDb ID и [Find By ID](https://developer.themoviedb.org/reference/find-by-id). Числовые movie ID и TV ID имеют разные пространства: хранить `(provider, mediaType, externalId)`. Поиск только по названию и году — запасной вариант с ручным подтверждением, особенно для ремейков.

### TVmaze

Есть публичные endpoints шоу, эпизодов, изображений и lookup по IMDb. API объявлен CC BY-SA с атрибуцией и ShareAlike; применимость к объединённой базе и отдельным изображениям требует оценки, поэтому не добавляем автоматически. Наличие открытого API не даёт гарантии нужного числа кадров. [Условия API](https://www.tvmaze.com/api).

## Права и доступность

Оплата API не равна разрешению на коммерческий показ и преобразование изображений. Отдельно подтвердить хранение, CDN, кропы, атрибуцию, процедуру удаления и лицензию на сами материалы. У TMDB бесплатный режим относится к некоммерческому использованию; коммерческий согласовывается отдельно. У Flim стандартные условия запрещают публичное развлекательное использование. [TMDB FAQ](https://developer.themoviedb.org/docs/faq), [Flim](https://flim.ai/terms-and-conditions).

Несколько агрегаторов могут иметь один исходный источник — это не независимая отказоустойчивость. Проверить доступ к API из будущего сервера и к изображениям из нескольких российских сетей. Сейчас эти измерения не выполнены.

## Как измерить и выбрать

Пилот: 15 произведений в каждой категории, всего 45. В каждой группе включить местный и зарубежный контент; в анимации — полный метр и сериалы. Это диагностическая, не репрезентативная выборка.

Для каждого произведения записывать: provider IDs, русское название, тип, число уникальных кандидатов кадров, число пригодных кадров после просмотра, пригодный постер, дубликаты, текст/водяные знаки, разрешение, доступность, время редактирования, статус прав. Для сериала важны разнообразные кадры, а не пять почти одинаковых изображений одного эпизода.

Критерий готовой загадки «Кадры»: 5 разных редакционно одобренных изображений с подтверждённой принадлежностью. Для «Лупы»: 1 пригодный постер и 5 проверенных областей раскрытия, не показывающих название. Порог в 5 — рабочий параметр прототипа, не ограничение API.

Выбирать по стоимости готовой загадки, а не цене запроса. Если ПоискКино закрывает нужную долю стартовых подборок, оставить его одного. Если STILL у Unofficial даёт больше пригодных кадров — подключить его как дополнительный источник. TMDB добавить для измеренных пробелов по постерам и сериалам.

## Что уже подготовлено

- Схема каталога с внешними ID, типом изображения, происхождением и независимыми статусами прав/редактуры.
- `pnpm api:probe` для bounded-запросов к трём кандидатам: до 2 запросов на произведение, до 3 для сериала TMDB с эпизодом.
- Отчёты первой страницы сохраняются локально и не попадают в Git. Скрипт не скачивает файлы и не объявляет кадры пригодными автоматически.

Для фактической проверки нужны ключи в локальном `.env`: POISKKINO_API_KEY, KINOPOISK_UNOFFICIAL_API_KEY, TMDB_READ_TOKEN. Не отправлять их в чат и не помещать в клиентские переменные.
