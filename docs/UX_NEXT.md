# Упрощение игры — согласованные изменения

- Главная: только вход в соло, онлайн, кастомные лобби и фильм дня.
- Онлайн: две быстрые игры — «Дуэль» (2 игрока) и «Компания» (4 игрока); поиск с анимацией, отменой и без формы настроек.
- Справа обновляемая лента завершённых публичных игр, без названий текущих загадок и приватных комнат.
- Кастомные лобби: каталог открытых комнат, вход по коду, создание публичной или приватной комнаты. Приватные доступны только по ссылке/коду.
- Таймер заметнее; в таблице личное время и статус каждого участника. После окончания личного времени явно показывать ожидание остальных.
- Максимум 20 очков: подсказки снижают награду, порядок правильных ответов дополнительно уменьшает её на 2 за предшествующего угадавшего (минимум 1). Соло сохраняет прежние очки.
- Рейтинг, подборки и дополнительные ссылки временно скрыты из навигации, код сохранён.
- Почта и пароль работают без обязательного подтверждения по умолчанию; включение EMAIL_VERIFICATION_REQUIRED=true возвращает проверку. Существующие пароли не заменяются повторной регистрацией.
- Кнопки Twitch/Яндекса пока скрыты.
