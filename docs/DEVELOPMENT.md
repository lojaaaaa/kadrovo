# Разработка и проверки

## Качество

- ESLint + TypeScript strict, noUncheckedIndexedAccess; ноль предупреждений.
- Prettier, EditorConfig, единые окончания строк.
- Husky: pre-commit запускает lint-staged и проверку типов; commit-msg проверяет Conventional Commits; pre-push запускает lint, typecheck и тесты.
- GitHub Actions: установка из lockfile, Prisma generate/validate, форматирование, lint, typecheck, tests, production build.
- Dependabot: обновления npm и GitHub Actions. Remote ещё не создан, поэтому GitHub CI и правила защиты ветки пока не активированы на сервере.
- ESLint 9.39.5 закреплён из-за peer-ограничений eslint-plugin-react/import/jsx-a11y в текущем eslint-config-next. Реестр помечает ветку устаревшей; перейти на ESLint 10 после совместимого обновления плагинов, не скрывать конфликт overrides.

## Первые тесты

Проверяются граница таймера, пауза ровно 3 секунды, повтор команды, запрет повторного начисления и сохранение возможности ответить для других игроков. Добавлены тесты состояния матча, приватности ответа, авторизации старта, переподключения и демокаталога; сетевые сценарии отдельно проверяют лобби и полный матч.

## База данных

Prisma 7 (стабильная ветка) + PostgreSQL 18. Начальная миграция описывает каталог, алиасы, внешние идентификаторы и источники изображений. Внешний ID включает тип медиа: числовые ID фильмов и сериалов TMDB могут пересекаться. Статусы прав и редакторской проверки хранятся отдельно и по умолчанию unreviewed.

Docker Compose поднимает PostgreSQL, миграции, NestJS, Next.js и Caddy. Хранилище изображений и Redis сейчас не запускаются: необходимость Redis не подтверждена, материалы для object storage ещё не импортировались.

## Границы этапа

Работают сетевая комната, гостевая сессия и полный игровой цикл на демоконтенте. Следующий срез — импорт и редакторская подготовка настоящих кинокадров и постеров. Подробнее: GAMEPLAY.md.

До публичного запуска нужны: интеграционный тест нескольких игроков, проверка восстановления соединения, CI на remote, мониторинг, резервное копирование, измеренная доступность материалов и подтверждённые права на их использование.

## Особенности текущего окружения

Next.js запускается и собирается с `--webpack`: Turbopack при обработке CSS пытался открыть служебный порт и получал запрет окружения. Это выбор сборщика, а не изменение архитектуры приложения. Возможность возврата к Turbopack можно проверить в обычном dev/CI окружении.
